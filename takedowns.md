# Takedowns Log

## Policy (Hard Guardrail)
- If **any** creator, streamer, representative, or rights holder requests removal of a clip:
  1. **Remove it the same day** on **Instagram, TikTok, and YouTube Shorts** (and delete any local queued bundles/renders for that clip).
  2. **Log the request and exact removal timestamps** in the table below.
  3. **Notify the human immediately** with the details.
  4. **Never DM or argue** with anyone without explicit human approval.
  5. Add the creator to the **Do-Not-Clip List** below if they request not to be clipped going forward.
